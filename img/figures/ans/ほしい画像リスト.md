# 答えの絵（`ansFig`）に、写真がほしいもの

`october.html` は、答えを出すときに大きな文字の上に「実物」の絵を出せる。
いまは県の木・鳥・花の**24枚が自作SVG**で入っている。ここに写真を足していく。

送ってもらえれば、まるく切り抜いて WebP にして入れる。**ファイル名は気にしなくてよい**
（何の写真かだけ一言そえてください）。表の「ファイル名」はこちらで付ける名前。

## 送る前に：どこの写真なら置けるか

**このリポジトリもサイトも公開されている。** だから「サイトに表示してよい」だけでは足りず、
**ファイルを置いて配ってよい**ものに限られる。

| 出どころ | 可否 | なぜ |
|---|---|---|
| **自分で撮った写真** | ◎ | 制限なし。いちばんよい |
| **Wikimedia Commons の PD / CC0** | ◎ | 再配布自由・クレジット不要 |
| **Wikimedia Commons の CC BY / CC BY-SA** | ○ | 再配布自由。ただし**撮影者名とライセンスの表記が要る** |
| 写真AC・ぱくたそ など | △ | 規約で**素材の再配布が禁止**。公開リポジトリに置くと引っかかる |
| 教材（テキスト・問題集）の写真 | ✕ | 複製・公衆送信になる。ぜったいに使わない |
| ネット検索で出てきた画像 | ✕ | ほぼ全部だれかの著作物 |

迷ったら **Wikimedia Commons でファイルのページを開き、ライセンス欄を見て送る**のが確実。

## 送るときは、画像ページのスクリーンショットも一緒に
