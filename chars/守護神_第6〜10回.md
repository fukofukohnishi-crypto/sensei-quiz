# 守護神 11体（後期 第6〜10回）

ニッポン制覇（`chizu.html`）に足した11都県の守護神カード。メダルとクイズは入れてあるので、
**絵が届けば完成**する。絵が無いあいだは、立ち絵は絵文字、メダルは🏅に落ちる。

- 中身（必殺技・紹介文・左のメダル10個）は、**テキストにあることだけ**で書いた。メダル10個は `chizu.html` のクイズと同じ語
- カードの番号は、これまでと同じく**県コード＋32**（長野52・京都58・鳥取63 と同じ並び）
- カードの id は**カード番号管理台帳（`card_number_management.xlsx`）の割り当てどおり** `r040`〜`r054`（県コード＋32。
  台帳は北海道 r33 → 沖縄 r79 の順で全県に割り当て済み）。いま `Cards.json` で空いていることも確かめた。
  絵がとどくまで `Cards.json` には入れない
  （先に入れると、コレクションに絵の無いカードが出るうえ、検証の「画像参照」で引っかかる）

## 絵がとどいたらすること

1. カード絵を WebP（q85）にして `card-images/<下の表のファイル名>` に置く
2. 立ち絵をカードから切り出す（CLAUDE.md「守護神の立ち絵はカードから切り出す」）→ `chars/portraits/<ローマ字>.webp`
3. メダルのシート（1都県10個）を切り出す → `chars/medals/kanto|chubu/<メダルのファイル名>.webp`
4. 下の「Cards.json に足すもの」を足し、`chizu.html` の `PREF_CARD_MAP` に県コードと id を書く
   → すでにメダル10個そろえていた子にも、つぎに開いたとき自動でカードが入る
5. 名前を絵にあわせて変えたら、`Cards.json` の `name` と `chizu.html` の `guardianName` の**両方**を直す

## カード絵のつくりかた（共通）

これまでの守護神カード（`card-images/r85_kyoto.webp` など）と**同じレイアウト**にする。
画像生成には、下の共通の指示＋1体ずつの指示をつなげて渡す。**県章の画像もいっしょに渡すこと**
（右上にえがかれる。あとで答えの絵としても切り出して使う）。

```
日本の子ども向けトレーディングカードのイラスト。縦長（3:4）。
豪華な金色のわく、黒地。迫力のあるアニメ・ゲーム風の絵で、キャラクターはコミカルで親しみやすく。
レイアウト：
・左上：六角形のわくに大きな数字（カード番号）。その右に、地方名と都道府県名のプレート
・右上：「R」の文字のプレート、その下に県章（添付の画像の形のまま）
・左はし：丸いアイコンが縦に10個。それぞれ名所や名産の小さな絵と、その名前の文字
・まん中：キャラクターと背景。右側に縦書きのキャッチコピー
・下の中央：名前のプレート（上に小さく「〇〇守護神」、大きく名前、その下に「〜 二つ名 〜」）
・その下：「必殺技」の帯と技の名前、技の小さな絵と説明文
・左下：「キャラクター紹介」の文章。右下：攻撃力・防御力・知識力・スピードの4本のゲージと数字、「タイプ」
文字はすべて日本語。
```
